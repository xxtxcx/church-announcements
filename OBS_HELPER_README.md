# OBS Helper - Інструкція з використання

## Опис

OBS Helper - це веб-додаток для використання як overlay/mask в OBS Studio. Він дозволяє показувати плашки з іменами ведучих поверх відео з камери або захоплення екрану.

## Основні функції

- **Плашка з ім'ям ведучого**: З'являється зліва, показується 5 секунд, зникає вправо
- **Прозорий фон**: Дозволяє бачити відео під overlay
- **OBS WebSocket інтеграція**: Можливість керування через OBS WebSocket API

## Налаштування

### 1. Запуск сервера синхронізації

**Важливо:** Для роботи синхронізації між браузером та OBS Browser Source потрібно запустити сервер синхронізації.

В окремому терміналі запустіть:

```bash
npm run sync-server
```

Або напряму:

```bash
node sync-server.js
```

Сервер запуститься на `http://localhost:3001` і буде синхронізувати команди між браузером та OBS.

**Примітка:** Якщо сервер не запущений, додаток спробує використати localStorage як fallback (може не працювати між браузером і OBS через різні контексти).

### 2. Налаштування OBS Studio

#### 2.1. Встановлення OBS WebSocket (опціонально)

1. Відкрийте OBS Studio
2. Перейдіть в `Tools` → `WebSocket Server Settings`
3. Увімкніть WebSocket сервер
4. Запишіть порт (за замовчуванням: 4455)
5. Встановіть пароль (опціонально, але рекомендовано)

#### 2.2. Додавання джерела в OBS

1. Створіть нову сцену або використайте існуючу
2. Додайте джерело `Browser Source`
3. Встановіть розміри: **1920x1080**
4. В URL вкажіть адресу вашого сайту: `http://localhost:3000/obs-helper` (або ваш production URL)
5. Увімкніть опцію **"Shutdown source when not visible"** (опціонально)
6. Увімкніть опцію **"Refresh browser when scene becomes active"**

#### 2.3. Налаштування прозорості

1. В налаштуваннях Browser Source знайдіть опцію **"Custom CSS"**
2. Додайте наступний CSS (опціонально, якщо потрібно додаткова прозорість):
```css
body {
  background-color: transparent !important;
}
```

## Використання

### Базове використання (через панель управління)

1. Відкрийте сайт в браузері з параметром `?control=true`:
   ```
   http://localhost:3000/obs-helper?control=true
   ```
   Або в production:
   ```
   https://your-domain.com/obs-helper?control=true
   ```

2. З'явиться панель управління в правому верхньому куті
3. Введіть ім'я та прізвище ведучого в поле
4. Натисніть кнопку "Показати плашку" або натисніть Enter

Плашка з'явиться зліва, показуватиметься 5 секунд і зникне вправо.

**Важливо:** В OBS Browser Source використовуйте URL **без** параметра `?control=true`, щоб панель управління не була видима в трансляції.

### Альтернативне використання (через консоль браузера)

Якщо потрібно використати через консоль:

1. Відкрийте сайт в браузері (або в OBS Browser Source)
2. Відкрийте консоль браузера (F12)
3. Виконайте команду:
```javascript
showHostName("Іван Петренко")
```

### Налаштування OBS WebSocket через URL

Можна налаштувати підключення до OBS через URL параметри:

```
http://localhost:3000/obs-helper?obs_url=ws://localhost:4455&obs_password=ваш_пароль
```

**Вимкнення OBS WebSocket:**

Якщо OBS не запущений або WebSocket не потрібен, можна вимкнути підключення:

```
http://localhost:3000/obs-helper?enable_obs=false
```

Це прибере помилки підключення з консолі та дозволить додатку працювати без OBS.

### Налаштування через localStorage

В консолі браузера виконайте:

```javascript
localStorage.setItem("obs_ws_url", "ws://localhost:4455");
localStorage.setItem("obs_ws_password", "ваш_пароль");
```

Потім перезавантажте сторінку.

## API

### `showHostName(name)`

Показує плашку з ім'ям ведучого.

**Параметри:**
- `name` (string) - Ім'я та прізвище ведучого

**Приклад:**
```javascript
showHostName("Марія Коваленко");
```

### `sendOBSRequest(requestType, requestData)`

Відправляє запит до OBS через WebSocket.

**Параметри:**
- `requestType` (string) - Тип запиту (наприклад, "GetSceneList", "SetCurrentScene")
- `requestData` (object) - Дані запиту

**Приклад:**
```javascript
sendOBSRequest("GetSceneList");
```

## Інтеграція з OBS

### Автоматичне показування плашки при зміні сцени

Можна налаштувати OBS для автоматичного показу плашки при перемиканні сцен. Для цього потрібно:

1. В OBS створіть скрипт або використайте плагін
2. При зміні сцени викликайте `showHostName()` через WebSocket або HTTP запит

### Приклад скрипта для OBS (Lua)

```lua
function on_scene_change()
    -- Отримати ім'я ведучого з назви сцени або іншого джерела
    local scene_name = obs.obs_frontend_get_current_scene()
    local host_name = "Іван Петренко" -- або отримати з назви сцени
    
    -- Відправити команду до браузера через WebSocket або HTTP
    -- (потрібна додаткова реалізація)
end
```

## Усунення проблем

### Плашка не з'являється

1. Перевірте, чи правильно викликається функція `showHostName()`
2. Перевірте консоль браузера на наявність помилок
3. Переконайтеся, що сторінка завантажилася повністю

### OBS WebSocket не підключається

1. Перевірте, чи увімкнений WebSocket сервер в OBS
2. Перевірте порт (за замовчуванням 4455)
3. Перевірте пароль (якщо встановлений)
4. Перевірте, чи не блокує файрвол з'єднання
5. **Якщо OBS не потрібен**: Додайте `?enable_obs=false` до URL, щоб вимкнути підключення та прибрати помилки

**Примітка:** Додаток працює повністю без OBS WebSocket. Підключення до OBS є опціональним і потрібне тільки для інтеграції з OBS подіями.

### Прозорість не працює

1. Переконайтеся, що в OBS Browser Source увімкнена опція прозорості
2. Перевірте CSS стилі в `src/index.css`
3. Переконайтеся, що фон сторінки прозорий
